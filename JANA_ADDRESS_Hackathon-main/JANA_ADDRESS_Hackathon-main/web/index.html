Адрес одной строкой превращается в точные поля

Jana Address разбирает адрес доставки, который клиент написал как удобно: область, город, район, улица, дом, квартира, подъезд, этаж. Курьеру больше не нужно уточнять детали по телефону.

Так система читает реальные строки из базы. Нажмите «Проверить адрес» и попробуйте свою.

Как это работает

  1. Разбор

    Каждая запись превращается в отдельные поля с уровнем уверенности.

  2. Справочник

    Район и жилой массив восстанавливаются по собственному справочнику.

  3. Проверка

    Неуверенные записи подсвечены. Их можно поправить вручную в таблице.

  4. Запуск

    Один docker compose up. Работает автономно, без сети.

Что внутри

Проверка адреса

Введите одну строку и сразу получите разбор, уровень уверенности и подсказку «Возможно, вы имели в виду».

Пакетная обработка

Загрузите файл, посмотрите разбор и вручную поправьте записи, в которых система не уверена.
